## 本版本包含内容

### 核心能力

- **metric-query** — 通过语义层 Gateway API 查询业务指标，支持时间筛选、维度分组、同环比/占比/排名等快速衍生计算
- **metric-attribution** — 多维度归因诊断（波动确认 → 因子拆解 → 维度归因 → 外部事件 → 综合结论）
- **dip-vap-dashboard** — 生成单文件可交互 HTML 仪表板（Chart.js，无需服务器）
- **dip-vap-feishu-card** — 飞书消息卡片集成，支持 KPI 摘要、趋势图、排行榜等卡片类型

## 关键设计决策

- data-analyst 定位为**子 Agent**，不设 `default: true`，不绑定飞书机器人
- 指标查询通过 **curl + Gateway API**（`gateway.can.aloudata.com`），鉴权使用 `CAN_API_KEY`
- 相对时间统一使用 `NOW()`，禁止硬编码日期（九条铁律 #1）
- 主 Agent 通过 `sessions_send` 转发请求，保持各来源会话隔离
