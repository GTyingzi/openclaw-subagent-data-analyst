## 变更内容

### v0.1 → v0.2

#### Breaking Change：API Key 配置方式变更

`CAN_API_KEY` 的存储和读取方式从 `~/.openclaw/.env` 改为仓库根目录的 `config.json`。

**旧方式（v0.1）**：
```bash
# ~/.openclaw/.env
CAN_API_KEY=cgk-xxxxxxxx
```

**新方式（v0.2）**：
```json
// config.json（仓库根目录）
{
  "CAN_API_KEY": "cgk-xxxxxxxx"
}
```

读取命令：
```bash
CAN_API_KEY=$(python3 -c "import json; print(json.load(open('../../config.json'))['CAN_API_KEY'])")
```

#### 升级指引

从 v0.1 升级时，将原有 `~/.openclaw/.env` 中的 Key 值填入仓库根目录的 `config.json`：

```bash
# 查看旧 Key
grep CAN_API_KEY ~/.openclaw/.env

# 写入 config.json
python3 -c "
import json
path = 'config.json'
cfg = json.load(open(path))
cfg['CAN_API_KEY'] = 'cgk-your-real-key'  # 替换为上面查到的值
json.dump(cfg, open(path,'w'), indent=2)
"
```
